# 🥗 MacroSnap

MacroSnap is an AI-powered nutrition chatbot built with Streamlit and Google Gemini.

It helps users understand what they are eating by analyzing meal descriptions or meal photos and estimating calories and macronutrients.

## ✨ Features

- 🥗 AI nutrition chatbot
- 📸 Analyze meal photos
- 💬 Describe meals using text
- 🔥 Estimate calories
- 💪 Estimate protein, carbohydrates, and fat
- 🤖 Powered by Google Gemini
- 📱 Send nutrition summaries to WhatsApp using Twilio
- 💬 Simple conversational interface built with Streamlit

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini
- Twilio WhatsApp API
